# Nebula Pop (Android)

Native Android cosmic bubble-puzzle game built with Kotlin, Jetpack Compose, Material 3, Navigation Compose, and Jetpack DataStore.

## Features

- **20 Handcrafted Cosmic Sectors**: Four progressive zones (*Orion Rim*, *Plasma Belt*, *Asteroid Rift*, *Singularity Core*) introducing **Ice-Locked Orbs** and **Armored Stone Asteroids**, with 1–3 star ratings.
- **Endless Arcade Mode**: Classic ceiling-drop survival mode with escalating waves and high-score tracking.
- **Ricochet Laser Sight & Orb Swapping**: Multi-bounce trajectory raycast preview with impact reticle and instant active/next orb swap.
- **Power-Up Orbs & Combo Fireball**: Consecutive pop combos charge the **Super Fireball**; tactical **Bomb**, **Lightning Bolt**, and **Wild** boosters can be armed from the bottom dock.
- **Arcade Juice & Accessibility**: Synthesized `AudioTrack` sound effects, haptic feedback, floating score popups, shockwave rings, damped screen shake, and an optional **Colorblind Symbols** mode.
